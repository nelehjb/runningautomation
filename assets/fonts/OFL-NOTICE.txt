Licence text: https://openfontlicense.org/open-font-license-official-text/
Source:       https://fonts.google.com (woff2 subsets: latin, latin-ext)

The fonts are unmodified; only the latin and latin-ext subsets are included
(Reenie Beanie is published as latin only). Montserrat is the variable file
Google Fonts serves, one per subset, with the weight axis pinned by each
@font-face rule.

Ekran and Cygre — the two other faces the graphic asks for — are NOT bundled:
they are not open-licensed, so no font file for them is kept in this
repository. See README.md in this folder.
